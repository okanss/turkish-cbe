# Reasoning grafikleri

Gerçek model verisi olmadığı için burada performans grafiği bulunmaz.
`turkish-cbe-reasoning analyse --output results/reasoning/YENI_RAPOR --figures`
gerçek kayıtları doğruladıktan sonra PDF/SVG/PNG'leri raporun `figures/`
altına yazar. Sentetik test grafikleri yalnız geçici test dizinlerinde kalır.
