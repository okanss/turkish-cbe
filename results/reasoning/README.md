# Reasoning deneyleri

Gerçek model sonucu yoktur. `plans/` yalnız deterministic dry-run planlarını
saklar; `no_model_results/analysis_manifest.json` bu durumu belgeler. Bunlar
doğruluk, yetkinlik veya performans artışı sonucu değildir. Raw/normalized
reasoning kayıtları yalnız açıkça yürütülmüş gerçek pilot sonrası oluşur.

Kullanım, şema ve sınırlamalar: [REASONING_EXPERIMENTS.md](../../REASONING_EXPERIMENTS.md).
