# Lexical ölçümler

baseline/ bağımsız lisanslı Türkçe korpus ve yerel tokenizer ölçümlerini
içerir; LLM performans veya tahmin sonucu içermez. Manifestte korpus,
model/tokenizer revision, kaynak/çıktı hashleri ve eksik kapsam kayıtlıdır.
Gerçek model kayıtları geldiğinde yeni, ayrı bir çıktı dizini kullanılmalıdır.
